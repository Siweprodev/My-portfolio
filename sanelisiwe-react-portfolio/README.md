# Sanelisiwe Sogiba — React Portfolio

A responsive, single-page developer portfolio built with React, Vite and plain CSS.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Extract this project folder.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing

Update `src/App.jsx`:
- Add your actual LinkedIn profile URL.
- Add your GitHub profile URL.
- Add a live demo and GitHub repository URL for The Tall Detailer when ready.
- Add other projects as you complete them.

The contact email and phone number currently use the details supplied in your CV.

## Build for deployment

```bash
npm run build
```

The production website is generated in the `dist` folder. You can deploy it to Vercel, Netlify or another static hosting provider.

## Notes

- This is a frontend portfolio only; it does not require a database or backend.
- The experience and education details are based on the supplied CV.
- The project preview is a designed placeholder, not a screenshot of the live website.
